# Portfolio de Genolie Rosette BALOUT

Portfolio professionnel réalisé avec GitHub Pages et Markdown dans le cadre du BTS SIO, option SISR.

## Modifier le portfolio

Les pages sont rédigées en Markdown (`.md`). Il est possible de les modifier directement depuis l'interface GitHub avec le bouton crayon.

## Publier avec GitHub Pages

1. Créer un dépôt GitHub nommé `portfolio` (ou choisir le nom souhaité).
2. Ajouter tous les fichiers et dossiers de ce projet à la racine du dépôt.
3. Ouvrir **Settings > Pages**.
4. Dans **Build and deployment**, choisir **Deploy from a branch**.
5. Choisir la branche `main` et le dossier `/ (root)`, puis enregistrer.
6. Attendre la publication et ouvrir l'adresse affichée dans la rubrique Pages.

Le site utilise le thème Minima de Jekyll. Les pages et les contenus sont écrits en Markdown ; aucun fichier HTML, CSS ou JavaScript n'est à rédiger pour cette version.

## À personnaliser

- Vérifier le nom du dépôt et l'adresse GitHub.
- Ajouter des captures d'écran et schémas dans `assets/images/`.
- Compléter les fiches projets avec les manipulations réellement effectuées.
- Ajouter les missions du stage SNCF à la fin du stage.
- Choisir les coordonnées que l'on souhaite rendre publiques.
