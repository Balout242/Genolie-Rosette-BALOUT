# Mise en place d'Active Directory avec Windows Server 2019

## Présentation

Dans le cadre de ma formation en BTS SIO SISR, j'ai réalisé un TP autour d'**Active Directory avec Windows Server 2019**, associé à une **station cliente Windows 10**.

## Environnement technique connu

- Serveur : Windows Server 2019.
- Service : Active Directory.
- Poste client : Windows 10.

## Objectif du projet

Mettre en place un environnement Active Directory avec un serveur Windows Server 2019 et un poste client Windows 10.

## Réalisation

Les détails de configuration (nom de domaine, adressage IP, rôles installés, création des utilisateurs ou groupes et intégration du poste client) seront ajoutés après confirmation des manipulations réellement effectuées.

## Résultats et preuves

À compléter : captures d'écran du serveur, de la console Active Directory et du poste client.

## Bilan personnel

À compléter : compétences mobilisées, difficultés rencontrées et solutions apportées.
