# Configuration de VLAN avec GNS3

## Présentation

Dans le cadre de ma formation en BTS SIO SISR, j'ai travaillé sur la configuration de **VLAN dans GNS3**.

## Environnement technique connu

- Outil de simulation : GNS3.
- Sujet : création et configuration de VLAN.

## Objectif du projet

Mettre en pratique la segmentation d'un réseau à l'aide de VLAN dans une maquette simulée.

## Réalisation

La topologie utilisée, le nombre de VLAN, le plan d'adressage, la configuration des équipements et les tests effectués seront ajoutés après confirmation des éléments du TP.
